# Barista Pro Mobile (Mini Katalog Uygulaması)

**Kısa açıklama:** Bu proje, Flutter kullanılarak geliştirilmiş temel bir mobil katalog uygulamasıdır. Cafe menüsündeki ürünlerin GridView ile listelenmesini, arama/filtreleme yapılmasını, Named Routes ile detay sayfasına geçişi ve basit bir sepet state'i güncellemeyi simüle eder. Eğitimdeki gün gün istenen tüm kazanımlar bu projede kodlanmıştır.

**Kullanılan Flutter Sürümü:** 3.x (Stabil)

**Çalıştırma Adımları:**
1. Proje dosyalarını bilgisayarınıza indirin.
2. Terminal veya Komut İstemcisi (CMD) üzerinden projenin ana dizinine (`cafe_mobile`) girin.
3. `flutter pub get` komutunu çalıştırarak paketleri yükleyin.
4. Herhangi bir emülatör açıkken veya fiziksel cihaz bağlıyken `flutter run` komutu ile uygulamayı başlatın.
